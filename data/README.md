# Data Directory

## static/

Runtime inputs used by `app.py`.

- `bond_10y_differentials.csv`: 10-year government bond differential versus the US.
- `valuation_ranks.csv`: static valuation rank inputs.
- `narrative_ranks.csv`: static narrative rank inputs.
- `mcap_data.csv`: market-cap liquidity input.
- `oil_imports_2024.xlsx`: crude oil import data used for oil sensitivity.

## reference_workbooks/

Archived source/reference workbooks from the pre-Streamlit Excel model. These are not runtime dependencies.

## reference_exports/

Archived sheet exports and scratch/reference CSVs from prior project stages. These are not runtime dependencies.
